# Precision-Divergence Class (PDC)

Use this skill when classifying a scientific disagreement that **grows as measurements get better**.

## Definition

Independent estimators of one named quantity, as formal uncertainties shrink, increase their mutual residual. The unknown is not the quantity. It is precision spent on incommensurable operators.

## Do not confuse with

| Class | Owns |
|---|---|
| CIC | Two clocks that cannot be compared |
| FAC | A named discriminator that licensed both camps |
| IRC | One published interval containing two qualitative worlds |
| ANC | Known record dropped because a required axis is null |
| UPRC | Extractable-dark vs gravitational-dark; unclosed redox column |
| PPC | Residuals absorbed by extra unobservable degrees of freedom |

PDC owns the **derivative** d(disagreement)/d(precision) > 0.

## Kill rule

- Later precision reduces the residual (hidden systematics win), OR
- A coupling/hybrid paper halves the residual.

A mid-landing third estimator does **not** kill. It is three-body PDC.

## Score

`40 × precision_gain × residual_growth × evidence × (1 − spoken) × (1 − prior_overlap)`

Require ≥2 estimators. Controls must score < 1.0. Subtract the class archive before minting. Never mint 150 per-realm discoveries (CLOSED-2026-09-30).
