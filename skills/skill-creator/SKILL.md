# Skill Creator — class-archive sessions

When a session mints a new *class* (not a substance):

1. Name it with a three-letter code if it will join the archive. Check GitHub `user:sENZ5hFx class 2026` so the code does not collide (PPC is Patch-Proliferation; do not reuse).
2. Write `skills/<class-slug>/SKILL.md` with: definition, do-not-confuse table, kill rule, score formula, type specimen, retired specimen.
3. Keep high-agency-partner as the routing skill: subtract archive, no 150-mint, publish both destinations.
4. Do not mark ordinary research pages as Notion skills. Only mark a page a skill when the user asked for reusable instructions.
5. Ship the skill in the GitHub repo `skills/` folder of that session.
